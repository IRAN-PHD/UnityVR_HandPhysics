# Realistic hand interaction for XR Interaction Toolkit in VR

<p align="center">
  <strong> UnityVR_HandPhysics </strong> is a ready-to-go project for Oculus Quest in Unity 2022.3.62f3. All necessary extensions are installed.

# Main features
- Realistic Hand Physics to interact with objects
- Simple geometry interactables in test scene
- ⚠️ *Under construction:* Finger sensor module for further development
- Ready to transfer prefabs to your own project

# Supported versions
- Unity 2022

## Hand tracking
- Oculus Quest 2/3 - Android

## Main Packages
- Animation Rigging
- XR Hands
- XR Interaction Toolkit
- XR Plugin Management

# Supported render pipelines
- Universal Render Pipeline (URP)
